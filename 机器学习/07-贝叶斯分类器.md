# 07 - 贝叶斯分类器：用"概率"说话的分类器

## 引入：医生怎么判断你得了什么病？

你发烧、咳嗽、喉咙痛去看医生。医生不会直接说"你是感冒"，而是心里估算：

- 在这个季节，感冒的概率本来就很高（**先验概率**）
- 如果真是感冒，出现"发烧+咳嗽+喉咙痛"这些症状的概率有多大（**似然**）
- 如果是流感，出现这些症状的概率又有多大

综合起来，医生得出：你大概率是感冒（80%），小概率是流感（15%），极小概率是其他病。

这个"根据观察到的症状，反推疾病概率"的过程，就是**贝叶斯定理**的核心思想。

---

## 贝叶斯定理：一个"反着算"的公式

贝叶斯定理其实就一句话：

$$P(类别|特征) = \frac{P(特征|类别) \times P(类别)}{P(特征)}$$

翻译成人话：**在观察到特征后，某个类别的概率 =（这个类别产生这些特征的可能性 × 这个类别本身出现的概率）÷ 特征出现的总概率**。

- **先验概率 P(类别)**：还没观察任何特征之前，你对类别的初始判断（如：这个季节80%的病是感冒）
- **似然 P(特征|类别)**：如果已知是感冒，出现"发烧+咳嗽"的概率
- **后验概率 P(类别|特征)**：观察到症状后，修正了的判断——这才是我们真正想要的

---

## 朴素贝叶斯："朴素"在哪？

如果要直接计算 `P(发烧, 咳嗽, 喉咙痛 | 感冒)`，你得知道这三个症状所有组合出现的概率——当特征很多时，穷举所有组合是不可能的。

**朴素贝叶斯的"朴素"假设**：假设所有特征之间**相互独立**。这样：

P(发烧, 咳嗽, 喉咙痛 | 感冒) = P(发烧|感冒) × P(咳嗽|感冒) × P(喉咙痛|感冒)

每个单独的概率都很容易从数据中统计出来！

> 这个假设在现实中往往不成立（发烧和咳嗽其实不是独立的），但神奇的是，朴素贝叶斯在很多任务上依然表现很好，而且**训练速度极快**。

---

## 拉普拉斯修正：解决"没见过"的问题

假设你的训练集里，没有任何感冒患者是"流清鼻涕"的。那么P(流清鼻涕|感冒) = 0，连乘后整个后验概率就变成0了——这显然不合理，只是因为你没见过而已。

**拉普拉斯修正**的做法：给每种可能性的计数都+1（相当于假设每种情况都至少出现过一次）。数据量大时，这个+1的影响微乎其微；数据量小时，它避免了概率为0的灾难。

---

## 贝叶斯网：当"朴素"假设不够用

朴素贝叶斯假设所有特征独立，但现实中特征间有依赖关系。比如：

- "下雨"和"地面湿"显然是相关的

**贝叶斯网（Bayesian Network）**用一个有向无环图来显式表达特征间的依赖关系。每个节点是一个变量，边表示"直接影响"。加上条件概率表，就构成一个完整的概率模型。

贝叶斯网能做的事情：
- **推理**：已知某些变量的值，推测其他变量的概率分布
- **学习**：从数据中自动学习网络结构（哪些变量之间有边）和参数

---

## 例题：用朴素贝叶斯做垃圾邮件分类

### 问题描述
经典的垃圾邮件过滤问题——根据邮件中的关键词判断是否为垃圾邮件。

### Python代码

```python
import numpy as np
from sklearn.naive_bayes import MultinomialNB, GaussianNB
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import classification_report, confusion_matrix
import pandas as pd

# 模拟20封邮件（有些是垃圾邮件，有些是正常邮件）
emails = [
    ("免费 领取 大奖 点击 这里 优惠 百万 现金", "垃圾"),
    ("会议 通知 明天 下午 三点 会议室", "正常"),
    ("恭喜 你 获得 了 特等奖 快 来 领取", "垃圾"),
    ("项目 进度 报告 请 查收 附件", "正常"),
    ("限时 优惠 错过 今天 再等 一年 点击", "垃圾"),
    ("周末 聚餐 大家 有 空 吗", "正常"),
    ("你 的 账户 存在 风险 请 立即 登录 验证", "垃圾"),
    ("论文 初稿 已经 完成 请 老师 审阅", "正常"),
    ("百万 大奖 现金 红包 免费 领取 不 要 错过", "垃圾"),
    ("课程 作业 提交 截止 日期 延后 通知", "正常"),
    ("恭喜 你 中奖 了 点击 链接 填写 银行卡 信息", "垃圾"),
    ("考试 安排 已经 发布 请 查看 官网", "正常"),
    ("特价 机票 内部 渠道 限时 抢购", "垃圾"),
    ("实验室 安全 培训 下周一 开始 签到", "正常"),
    ("兼职 日结 轻松 月入 过万 联系 QQ", "垃圾"),
    ("明天 组会 汇报 PPT 准备 好了 吗", "正常"),
    ("无抵押 贷款 秒批 额度 高达 50万", "垃圾"),
    ("毕业 答辩 时间 安排 通知", "正常"),
]

X_text = [e[0] for e in emails]
y = [1 if e[1] == "垃圾" else 0 for e in emails]

# 将文本转换成词频特征
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(X_text)

print(f"词汇表大小: {len(vectorizer.get_feature_names_out())}")
print(f"垃圾邮件: {sum(y)} 封, 正常邮件: {len(y)-sum(y)} 封")

# 训练朴素贝叶斯（多项式模型，适合文本分类）
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

nb = MultinomialNB(alpha=1.0)  # alpha=1 即拉普拉斯平滑
nb.fit(X_train, y_train)

# 交叉验证
cv_scores = cross_val_score(nb, X, y, cv=5)
print(f"\n5折交叉验证精度: {cv_scores.mean():.2%} (±{cv_scores.std():.2%})")

# 测试
y_pred = nb.predict(X_test)
print(f"\n测试集报告:")
print(classification_report(y_test, y_pred, target_names=['正常', '垃圾']))

# 查看哪些词最能区分垃圾邮件
feature_names = vectorizer.get_feature_names_out()
spam_log_prob = nb.feature_log_prob_[1]  # 垃圾邮件类别的对数概率
normal_log_prob = nb.feature_log_prob_[0]  # 正常邮件类别的对数概率
diff = spam_log_prob - normal_log_prob

top_spam_idx = np.argsort(diff)[-10:][::-1]
print("\n最能代表垃圾邮件的词:")
for idx in top_spam_idx:
    print(f"  '{feature_names[idx]}': 差异得分={diff[idx]:.2f}")

# 试一封新邮件
new_email = ["恭喜 你 获得 了 免费 大奖 点击 领取"]
new_vec = vectorizer.transform(new_email)
pred = nb.predict(new_vec)[0]
proba = nb.predict_proba(new_vec)[0]
print(f"\n新邮件: '{new_email[0]}'")
print(f"预测: {'垃圾' if pred == 1 else '正常'}")
print(f"概率 - 正常: {proba[0]:.4f}, 垃圾: {proba[1]:.4f}")
```

### 解读
- 朴素贝叶斯在文本分类上效果极好，这里完全分类正确（数据量虽小但特征明显）
- 模型发现"点击""领取""免费""大奖"等词与垃圾邮件强相关——这跟我们的直觉完全吻合
- 拉普拉斯平滑(alpha=1)确保了即便某个词在训练集中没出现过也不会导致概率为0
- 朴素贝叶斯特别适合文本分类：**训练快、可解释、在小数据上也表现不错**

---

## 小结

> 贝叶斯分类器的核心：用先验概率和观测数据，反推出后验概率。朴素贝叶斯用"特征独立"的大胆假设换取极快的训练速度，在文本分类领域是常青树。如果要建模特征间的依赖关系，上贝叶斯网。如果数据有缺失值需要估计，上EM算法。
