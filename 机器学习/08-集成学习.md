# 08 - 集成学习：三个臭皮匠，顶个诸葛亮

## 引入：你信任一个人，还是一群人？

假设你要做一道生死攸关的选择题，有两个方案：

- **方案A**：问一个正确率80%的专家，他说什么你就选什么
- **方案B**：问10个正确率只有65%的"半吊子"专家，投票决定

直觉上你可能选A。但实际算下来：方案A的错误率是20%。方案B呢？只有当超过5个人同时犯错时才选错——这个概率是多少？约3%！

这就是**集成学习（Ensemble Learning）**的魔法：**把一堆不那么强的"弱学习器"组合起来，能变成一个超强的"强学习器"。**

> 过去十年，几乎所有Kaggle竞赛、KDD Cup、Netflix Prize的冠军方案都用到了集成方法。想赢比赛？上集成。

---

## 为什么集成有效？

集成要有效，个体学习器必须满足两个条件：

1. **"好"**：每个个体至少要比随机猜测好（>50%准确率）
2. **"不同"**：个体之间要犯不同的错误——如果大家都犯同样的错误，集成也没用

一个经典例子：
- 学习器A、B、C都对2/3的样本正确
- 它们的错误样本各不相同
- 投票后：对每个样本，至少2/3的概率被正确分类 → 整体正确率接近100%

但如果A、B、C错的全是同一批样本——投票后依然是66.6%，毫无提升。

**多样性（Diversity）是集成的灵魂。**

---

## 两大流派

### Bagging：用随机性制造"不同"

**思路**：从原始数据中随机采样（有放回），生成T份不同的训练集，训练T个模型，让它们投票。

- **随机森林（Random Forest）**就是Bagging+决策树的经典组合——不仅数据随机采，每次分裂时也只随机看一部分特征，双重随机性让树与树之间差异更大
- Bagging特别适合**不稳定的基学习器**（如决策树、神经网络），这些模型对数据微小的变化很敏感，正好产生多样性
- 对稳定的模型（如SVM、朴素贝叶斯），Bagging效果不好——数据变来变去，模型预测结果还是差不多

### Boosting：用"纠错"来接力

**思路**：先训练第一个模型，看它在哪些样本上错了，训练第二个模型时"重点关注"这些错题，第三个模型再关注前两个还搞不定的……最后加权组合所有模型。

- **AdaBoost**：根据上一轮的错误率调整每个样本的权重，错得多的样本权重增加，下一轮训练时会受到更多"关注"
- **Gradient Boosting**：每一轮新模型专门去拟合前一轮的"残差"（即：真实值 - 当前集成模型的预测值），相当于不断地弥补前辈的错误
- **XGBoost / LightGBM**：Gradient Boosting的工程优化版，加入了正则化、并行计算等，是Kaggle竞赛的常胜将军

---

## Stacking：用模型来"调度"模型

Bagging和Boosting的结合方式是固定的（投票或加权平均）。有没有更好的结合方式？**Stacking**的思路：训练一个"元学习器"来学习怎么最好地组合各个基学习器的输出。

比如：你有逻辑回归、决策树、SVM三个模型，把它们各自的预测概率作为"新特征"，训练一个最终模型来决定每个基模型的话语权。这个最终模型通常是逻辑回归。

## 例题：用随机森林做红酒品质分类

### 问题描述
基于红酒的化学特征（酸度、糖度、pH值等），用随机森林判断红酒品质等级。

### Python代码

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.ensemble import BaggingClassifier, AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import classification_report, accuracy_score
from sklearn.datasets import load_wine

# 加载红酒数据集
wine = load_wine()
X, y = wine.data, wine.target

print(f"数据: {X.shape[0]} 个样本, {X.shape[1]} 个特征")
print(f"类别: {wine.target_names}")
print(f"特征: {wine.feature_names}")

# 划分数据
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

# 对比四种集成方法
models = {
    '单棵决策树': DecisionTreeClassifier(random_state=42),
    'Bagging': BaggingClassifier(
        DecisionTreeClassifier(), n_estimators=100, random_state=42
    ),
    '随机森林': RandomForestClassifier(n_estimators=100, random_state=42),
    'AdaBoost': AdaBoostClassifier(
        DecisionTreeClassifier(max_depth=2), n_estimators=100, random_state=42
    ),
    'GradientBoosting': GradientBoostingClassifier(
        n_estimators=100, learning_rate=0.1, random_state=42
    ),
}

print("\n各模型5折交叉验证结果:")
print("=" * 55)
for name, model in models.items():
    cv_scores = cross_val_score(model, X_train, y_train, cv=5)
    print(f"{name:15s} | CV精度: {cv_scores.mean():.3f} (±{cv_scores.std():.3f})")

# 最终用随机森林评估
print("\n" + "=" * 55)
print("【随机森林】详细评估:")
rf = models['随机森林']
rf.fit(X_train, y_train)
y_pred = rf.predict(X_test)

print(f"\n测试集准确率: {accuracy_score(y_test, y_pred):.2%}")
print("\n分类报告:")
print(classification_report(y_test, y_pred, target_names=wine.target_names))

# 特征重要性
importances = rf.feature_importances_
indices = np.argsort(importances)[::-1]
print("最重要的5个特征:")
for i in range(5):
    print(f"  {wine.feature_names[indices[i]]}: {importances[indices[i]]:.3f}")
```

### 解读
- 单棵决策树CV精度0.880，而随机森林直接拉到0.977——**集成的威力一目了然**
- AdaBoost略低于随机森林，这是因为它的基学习器被限制为max_depth=2的"弱"树，在这个小数据上有点太弱了
- 特征重要性告诉我们：proline（脯氨酸）和color_intensity（颜色强度）是区分红酒品种的最强信号
- 随机森林是很多实际问题的"首选baseline"——不需要调太多参就能表现不错

---

## 小结

> 集成学习的核心口诀：**好而不同**。Bagging靠随机采样制造多样性（并行训练），Boosting靠纠错机制接力提升（串行训练），Stacking让模型学习如何调度模型。在绝大多数实际任务中，集成方法都能稳定地优于单个模型。
