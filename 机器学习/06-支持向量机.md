# 06 - 支持向量机：找一条最"宽"的分界线

## 引入：修一堵最宽的墙

想象你是甲方，要在两个小区之间修一堵围墙，把高档小区和普通小区隔开。你可以把墙修在正中间，也可以紧贴其中一侧。

显然，**修在正中间**最好——给两侧都留出足够的空间，将来有新的建筑（新样本）进来，也不太容易"越界"。这堵墙在机器学习里叫**分类超平面**，墙到两边最近房子的距离叫**间隔（Margin）**，而支持向量机（SVM）的目标就是：**找到让间隔最大的那堵墙。**

"正中间"的位置意味着**鲁棒性最强、泛化能力最好**——这是SVM的核心直觉。

---

## 核心机制：怎么就变成了优化问题？

SVM的数学推导比前面几个算法复杂，但思路清晰：

**目标**：最大化间隔 → **约束**：所有样本都要在各自那侧（至少在边界外）

通过拉格朗日乘子法，这个问题可以转化成它的"对偶问题"求解，得到一个优美的结论：

> 最终模型**只由"支持向量"决定**——就是那些刚好压在边界上的样本点。其他离边界很远的样本，对模型没有影响！

这就是SVM名字的由来，也是它"稀疏性"的来源。

---

## 核技巧：在"高维空间"里画线

如果数据长这样——红点和蓝点混在一起，在二维平面上根本画不出直线来分开它们，怎么办？

**把数据映射到高维空间！** 一个神奇的数学事实是：如果原始空间是有限维的，那么一定存在一个高维空间，让数据在其中线性可分。

但问题来了：映射到高维后，计算两个点的内积会非常昂贵。**核函数（Kernel Function）**的巧妙之处在于：它直接在原始空间算出高维空间的内积结果，不需要真的做映射。

常用核函数：
- **线性核**：不映射，直接在原始空间做。文本分类常用
- **高斯核（RBF）**：最常用的非线性核，几乎可以拟合任意边界
- **多项式核**：适合已知数据有特定多项式关系的场景

> 经验法则：不知道用什么核 → 先试高斯核。文本数据 → 用线性核。

---

## 软间隔：允许"犯点小错"

现实中数据往往有噪声，强行要求所有样本都被完美分开可能导致过拟合。**软间隔（Soft Margin）**允许模型在某些样本上"放水"——引入松弛变量，对违反约束的样本施加惩罚。

惩罚力度由一个参数C控制：
- C很大：对错误零容忍 → 间隔窄，可能过拟合
- C很小：允许犯错 → 间隔宽，模型更稳健

---

## 例题：用SVM做人脸识别

### 问题描述
使用Labeled Faces in the Wild (LFW)数据集的一个子集，用SVM进行人脸识别。

### Python代码

```python
import numpy as np
from sklearn.svm import SVC
from sklearn.datasets import fetch_lfw_people
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.metrics import classification_report, accuracy_score
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 加载人脸数据集（选择至少有70张照片的人）
print("加载LFW人脸数据...")
lfw = fetch_lfw_people(min_faces_per_person=70, resize=0.4)
n_samples, h, w = lfw.images.shape
X = lfw.data
y = lfw.target
target_names = lfw.target_names
n_classes = len(target_names)

print(f"样本数: {n_samples}, 图片大小: {h}×{w}")
print(f"类别数: {n_classes} (每人至少70张照片)")
print(f"人物: {target_names}")

# 划分数据
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

# PCA降维（人脸数据维度很高，先降维再分类）
pca = PCA(n_components=150, whiten=True, random_state=42)
X_train_pca = pca.fit_transform(X_train)
X_test_pca = pca.transform(X_test)
print(f"\nPCA降维: {X.shape[1]} → 150, 保留方差比: {pca.explained_variance_ratio_.sum():.2%}")

# 用GridSearch找最佳SVM参数
param_grid = {
    'C': [1, 10, 100],
    'gamma': [0.001, 0.005, 0.01],
    'kernel': ['rbf']
}
svm = SVC(class_weight='balanced', random_state=42)
grid = GridSearchCV(svm, param_grid, cv=3, scoring='accuracy', n_jobs=-1)
grid.fit(X_train_pca, y_train)

print(f"\n最佳参数: {grid.best_params_}")
print(f"交叉验证精度: {grid.best_score_:.3f}")

# 最终评估
best_svm = grid.best_estimator_
y_pred = best_svm.predict(X_test_pca)

print(f"\n测试集准确率: {accuracy_score(y_test, y_pred):.2%}")
print("\n分类报告:")
print(classification_report(y_test, y_pred, target_names=target_names))

# 支持向量数量
print(f"支持向量数量: {len(best_svm.support_)}")
print(f"支持向量占比: {len(best_svm.support_)/len(X_train):.2%}")
```

### 输出（示例）
```
样本数: 1288, 图片大小: 50×37
类别数: 7 (每人至少70张照片)

PCA降维: 1850 → 150, 保留方差比: 90.23%

最佳参数: {'C': 10, 'gamma': 0.005, 'kernel': 'rbf'}
交叉验证精度: 0.831

测试集准确率: 85.09%

支持向量数量: 573
支持向量占比: 59.32%
```

### 解读
- 先用PCA把1850维降到150维，既去噪又加速SVM训练
- C=10意味着对错误有一定的容忍度，但不放纵
- 用高斯核（RBF）捕捉人脸特征的非线性关系
- 约59%的训练样本成为支持向量——说明人脸识别确实不是个简单问题
- 85%准确率在只有150个PCA特征的条件下算不错了

## 扩展：SVM也能做回归！

SVM不只是分类器。**SVR（Support Vector Regression）**用类似的思路做回归——在预测线周围画一个宽度为2ε的"管道"，管道内的样本不计入损失，只惩罚掉到管道外的点。这比普通线性回归更稳健，对异常值不敏感。

---

## 小结

> SVM的本质：找一个让"间隔"最大化的分类超平面。遇到线性不可分的数据 → 核函数映射到高维空间。允许少量错误的软间隔。最终模型只由少数"支持向量"决定，具有很好的稀疏性和泛化能力。
