# 02 - 模型评估与选择：你的模型到底靠不靠谱？

## 引入：考满分≠学得好

假设你是老师，你发现小明把课本上的例题背得滚瓜烂熟，每次做课后题都全对。但期末考试一换新题，他就懵了。

这在机器学习里叫**过拟合（Overfitting）**——模型把训练数据"背"下来了，但遇到没见过的新数据就拉胯。

反过来，如果小明连课本例题都做不对，那就是**欠拟合（Underfitting）**——模型连训练数据都没学好。

> 一个真正好的模型：训练数据上表现不错，**更重要的是**，没见过的新数据上表现也好。这种能力叫**泛化（Generalization）**。

---

## 怎么拿到"考试成绩"？——评估方法

我们不能等模型上线了才知道它好不好。得在训练阶段就模拟"期末考试"。

### 三种常见方法

**1. 留出法（Hold-out）**
直接把数据切成两份：70%训练，30%测试。简单粗暴，但要注意保持数据分布一致（比如原数据男女比例1:1，切出来的训练集也应该是1:1）。

**2. 交叉验证（Cross-Validation）**
把数据分成5份，每次用4份训练、1份测试，轮换5次，取平均成绩。数据少的时候特别好用。

**3. 自助法（Bootstrap）**
从原始数据里"有放回"地随机抽，抽出一个跟原数据一样大的训练集。大约36.8%的数据不会被抽到，刚好当测试集。数据很少时用这个。

---

## 考卷怎么打分？——性能度量

不同任务用不同的"打分标准"：

| 任务类型 | 最常用指标 | 一句话解释 |
|----------|-----------|-----------|
| 分类 | **准确率（Accuracy）** | 预测对了几个 / 总共有几个 |
| 分类 | **精确率（Precision）** | 预测为"好瓜"的里面，真正好的比例 |
| 分类 | **召回率（Recall）** | 真正的好瓜中，被找出来了多少 |
| 分类 | **AUC** | 模型把好瓜排在坏瓜前面的概率 |
| 回归 | **均方误差（MSE）** | 预测值与真实值差的平方的平均 |

### 一个经典矛盾：精确率 vs 召回率

抓间谍：你怀疑10个人，抓了其中1个，结果是真间谍 → 精确率100%，但召回率可能很低（还有99个间谍没抓到）。

反过来，你把所有人都抓了 → 召回率100%，但精确率接近0%。

**F1分数**是两者的调和平均：`F1 = 2 × (P × R) / (P + R)`，兼顾两者。

---

## 偏差 vs 方差：模型的两难困境

- **偏差（Bias）**：模型的"准头"——预测值与真实值的差距。偏差高 = 没瞄准
- **方差（Variance）**：模型的"稳定性"——换一批训练数据，结果波动大不大。方差高 = 手抖

**这对冤家永远在打架**：
- 简单模型（如线性回归）：偏差高，方差低 → 可能欠拟合
- 复杂模型（如深层神经网络）：偏差低，方差高 → 可能过拟合

你的任务：**在偏差和方差之间找到最佳平衡点**。

## 例题：比较KNN在不同k值下的表现

### 问题描述
用鸢尾花数据集，比较k=1和k=15时KNN的表现差异，直观理解偏差-方差权衡。

### Python代码

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import cross_val_score, train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score, classification_report
import numpy as np

# 加载鸢尾花数据集
iris = load_iris()
X, y = iris.data, iris.target

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)

# 对比不同k值
for k in [1, 3, 5, 10, 15]:
    model = KNeighborsClassifier(n_neighbors=k)
    # 5折交叉验证
    cv_scores = cross_val_score(model, X_train, y_train, cv=5)
    model.fit(X_train, y_train)
    test_score = model.score(X_test, y_test)

    print(f"k={k:2d} | CV均值: {cv_scores.mean():.3f} | "
          f"CV标准差: {cv_scores.std():.3f} | 测试精度: {test_score:.3f}")

# 最佳模型预测
best_k = 5
best_model = KNeighborsClassifier(n_neighbors=best_k)
best_model.fit(X_train, y_train)
y_pred = best_model.predict(X_test)
print(f"\n最终选择 k={best_k} 的模型")
print(f"测试集准确率: {accuracy_score(y_test, y_pred):.2%}")
```

### 输出
```
k= 1 | CV均值: 0.943 | CV标准差: 0.030 | 测试精度: 0.956
k= 3 | CV均值: 0.943 | CV标准差: 0.030 | 测试精度: 0.956
k= 5 | CV均值: 0.952 | CV标准差: 0.030 | 测试精度: 0.956
k=10 | CV均值: 0.933 | CV标准差: 0.044 | 测试精度: 0.911
k=15 | CV均值: 0.933 | CV标准差: 0.044 | 测试精度: 0.889
```

### 解读
- k=1时方差较大（模型太敏感，每个邻居都听），是**过拟合**倾向
- k=15时偏差增大（模型太"佛系"，看了太多邻居反而判断不准），是**欠拟合**倾向
- k=5是一个不错的折中

这就是**偏差-方差权衡**在真实代码中的体现！

## 小结

> 模型评估的核心三问：怎么考（评估方法）→ 怎么打分（性能度量）→ 分数的差异是运气还是实力（比较检验）。记住，训练集上全对不叫厉害，**新数据上表现好**才是真本事。
