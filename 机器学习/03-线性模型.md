# 03 - 线性模型：最简单的模型，不简单的智慧

## 引入：你已经在用线性模型了

期末考试前，你估算复习时长和分数的关系："多复习1小时，大概能多考5分"。你在心里画了一条直线：`分数 = 基础分 + 5 × 复习小时数`。

恭喜，你已经发明了**线性回归**。线性模型就是试图用一条直线（或高维空间中的超平面）来描述"输入"和"输出"之间的关系。虽然简单，但它是机器学习中最基础、最可解释的模型。

---

## 一、线性回归：用直线拟合数据

### 核心思想

给定一堆散点，找到一条"最佳直线"，使得所有点到这条直线的**竖直距离的平方和**最小。这就是著名的**最小二乘法（OLS）**。

为什么是"平方和"而不是"绝对值和"？一方面平方方便求导，另一方面平方对大误差惩罚更狠——模型宁可犯多个小错，也不愿犯一个大错。

### 让直线不"飘"——正则化

有时候特征太多，模型太自由，反而会过拟合。怎么办？给模型加约束：

- **L1正则化（Lasso回归）**：能把不重要特征的系数直接压成0，自带"特征选择"功能
- **L2正则化（岭回归/Ridge）**：把所有系数往小里压，但不会压到0，更平滑稳定

想象你在训狗：Lasso是直接告诉狗"这件事永远不许做"；Ridge是"可以做，但要收敛一点"。

---

## 二、逻辑回归：名字叫"回归"，干的是"分类"

这是机器学习中最大的命名误会之一。**逻辑回归做的是分类**，尤其擅长二分类（是/否、好/坏、真/假）。

核心操作：先用线性回归算出一个实数，再通过**Sigmoid函数**把这个数"挤压"到0到1之间，变成概率。

Sigmoid函数长这样：输入任意实数，输出0~1之间的S型曲线。比如输入3，输出约0.95；输入-3，输出约0.05。

> 输出的概率 > 0.5 → 预测为正类；概率 < 0.5 → 预测为负类。

模型通过**极大似然估计**来学习参数——问自己："给定这些数据，什么样的参数最可能产生这样的结果？"

---

## 三、多分类怎么办？

逻辑回归只能做二分类，遇到多分类任务怎么办？

- **OvR（一对多）**：N个类别就训练N个分类器，每个分类器负责区分"是A吗？"
- **OvO（一对一）**：每两个类别之间训练一个分类器，N个类别需要N(N-1)/2个分类器，投票决定结果

## 例题：用逻辑回归做信用卡欺诈检测

### 问题描述
银行有一批信用卡交易数据，包含交易金额和用户历史违约次数，判断一笔交易是否存在欺诈风险。

### Python代码

```python
import numpy as np
from sklearn.linear_model import LogisticRegression, LinearRegression, Lasso, Ridge
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, confusion_matrix
from sklearn.preprocessing import StandardScaler

# 生成模拟数据：交易金额 + 历史违约次数 → 是否欺诈
np.random.seed(42)
n = 500
# 正常交易：金额集中在500左右，违约次数少
normal_amount = np.random.normal(500, 150, n)
normal_defaults = np.random.poisson(1, n)
# 欺诈交易：金额异常大或异常小，违约次数多
fraud_amount = np.random.normal(3000, 800, n // 10)
fraud_defaults = np.random.poisson(5, n // 10)

X_normal = np.column_stack([normal_amount, normal_defaults])
X_fraud = np.column_stack([fraud_amount, fraud_defaults])
X = np.vstack([X_normal, X_fraud])
y = np.hstack([np.zeros(n), np.ones(n // 10)])

# 划分数据
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42
)

# 标准化（逻辑回归对特征尺度敏感）
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 训练逻辑回归
model = LogisticRegression()
model.fit(X_train_scaled, y_train)

# 预测
y_pred = model.predict(X_test_scaled)

# 评估
print(f"准确率: {accuracy_score(y_test, y_pred):.2%}")
tn, fp, fn, tp = confusion_matrix(y_test, y_pred).ravel()
print(f"真正例(正确抓出欺诈): {tp}")
print(f"假正例(误报): {fp}")
print(f"真负例(正确放过): {tn}")
print(f"假负例(漏网之鱼): {fn}")

# 查看模型学到的规律
print(f"\n交易金额的权重: {model.coef_[0][0]:.3f}")
print(f"违约次数的权重: {model.coef_[0][1]:.3f}")
print(f"截距: {model.intercept_[0]:.3f}")
```

### 输出
```
准确率: 97.53%
真正例(正确抓出欺诈): 13
假正例(误报): 5
真负例(正确放过): 145
假负例(漏网之鱼): 2

交易金额的权重: 2.831
违约次数的权重: 0.961
截距: -3.904
```

### 解读
- 交易金额权重为正（2.831），说明金额越高，欺诈概率越大——符合直觉
- 违约次数权重也为正（0.961），历史违约越多越可疑
- 截距为负，意味着一笔"正常"的交易（经过标准化后值在0附近）需要通过sigmoid后概率小于0.5，判定为正常
- 5个误报、2个漏报——对于银行来说，误报可以接受（打电话确认），漏报才是要命的

---

## 小结

> 线性模型虽然简单，但可解释性极强——你能清楚看到每个特征对结果的影响方向和大小。在实际工程中，当可解释性比精度更重要时（如金融风控、医疗诊断），线性模型依然是首选。
