# 09 - 聚类：没有标签时，怎么自动分组？

## 引入：老师拿来一筐水果，让小朋友分组

有个经典的段子：

> 老师拿来苹果和梨，让小朋友分成两份。
> - 小明按大小分：大果放一堆，小果放一堆。老师点头：嗯，体量感。
> - 小芳按颜色分：红果放一堆，非红放一堆。老师点头：颜色感。
> - 小武拿出眼镜：最新款，能看到水果里有几个籽。左边单数，右边双数。老师很高兴：**新的聚类算法诞生了。**

这个段子的精髓在于：**聚类没有绝对标准**。不同的视角（大小、颜色、籽数）会产生完全不同的分组结果，而且每种结果在各自的角度下都是"合理"的。

这也是聚类最难的地方——你让模型自动分组，但"什么叫好分组"这件事本身就依赖于你的业务目标。

---

## 聚类 vs 分类

| | 分类（Classification） | 聚类（Clustering） |
|---|---|---|
| 标签 | 训练数据有标签 | 没有任何标签 |
| 目标 | 学到"标签规律"，预测新样本 | 自动把相似的样本聚到一起 |
| 举例 | 给定100个已标注好/坏的瓜，判断新瓜好坏 | 给100个未知的瓜，让模型自己分组 |
| 常见算法 | 决策树、SVM、神经网络 | k-means、DBSCAN、层次聚类 |

---

## 三大流派

### 1. 原型聚类：假设每个簇有个"中心"

**k-means**是聚类界的"Hello World"：

1. 随机选k个点作为初始簇中心
2. 把每个样本分给离它最近的中心
3. 重新计算每个簇的中心（所有成员的均值）
4. 重复2-3，直到中心不再变化

k-means简单、快速，但有两个致命弱点：
- 必须**提前指定k**（分几组）
- 只能发现**球形**的簇，遇到弯弯曲曲的簇就抓瞎

**GMM（高斯混合模型）**是k-means的"概率升级版"：它不硬性规定"你属于A簇"，而是给出"你有70%概率属于A，20%属于B，10%属于C"。用EM算法迭代优化。

### 2. 密度聚类：哪里密，哪里就是一个簇

**DBSCAN**不关心"簇中心"，而是看"密度"：

- **核心点**：周围一定半径内至少有minPts个邻居
- 核心点连成一片 → 形成一个簇
- 孤立的点 → 噪声

DBSCAN的厉害之处：
- 不用指定簇的数量！
- 可以发现**任意形状**的簇
- 自动识别噪声点

### 3. 层次聚类：自底向上地合并

**AGNES**的思路：
1. 一开始每个样本自己就是一个簇
2. 每次合并最相似的两个簇
3. 直到所有样本合到同一个簇里

整个过程形成一棵树，你可以在任意高度"切一刀"得到不同粒度的聚类结果。

---

## 距离怎么算？

聚类的核心是"相似度"，而相似度的核心是"距离"。常用距离：

| 距离 | 公式感觉 | 适用场景 |
|------|----------|----------|
| 欧氏距离 | 两点之间的直线距离（勾股定理） | 连续数值特征 |
| 曼哈顿距离 | 只能走直角边的距离（如街区） | 高维稀疏数据 |
| 闵可夫斯基距离 | 以上两者的通式 | p=2即欧氏，p=1即曼哈顿 |

对无序离散属性（如颜色：红/绿/蓝），可以用VDM（Value Difference Metric）——两个颜色值在不同簇中的分布越相似，距离越近。

## 例题：用k-means做客户分群

### 问题描述
一家超市有客户的年收入和年消费数据，希望将客户分为3类以便精准营销。

### Python代码

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.mixture import GaussianMixture
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score

# 生成模拟客户数据
np.random.seed(42)
n = 300

# 三类客户：节俭型、均衡型、土豪型
cluster1 = np.column_stack([
    np.random.normal(30, 8, n//3),   # 年收入3万左右 → 低收入
    np.random.normal(15, 5, n//3)    # 年消费1.5万左右 → 低消费（节俭）
])
cluster2 = np.column_stack([
    np.random.normal(60, 10, n//3),  # 年收入6万 → 中等收入
    np.random.normal(55, 8, n//3)    # 年消费5.5万 → 中消费（均衡）
])
cluster3 = np.column_stack([
    np.random.normal(120, 25, n//3), # 年收入12万 → 高收入
    np.random.normal(100, 20, n//3)  # 年消费10万 → 高消费（土豪）
])

X = np.vstack([cluster1, cluster2, cluster3])

# 标准化（聚类对尺度敏感）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 对比三种聚类方法
fig, axes = plt.subplots(1, 4, figsize=(18, 4.5))

# 原始数据
axes[0].scatter(X[:, 0], X[:, 1], c='gray', alpha=0.6, s=20)
axes[0].set_title('原始数据', fontsize=12)
axes[0].set_xlabel('年收入(千元)'); axes[0].set_ylabel('年消费(千元)')

# k-means
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
labels_km = kmeans.fit_predict(X_scaled)
axes[1].scatter(X[:, 0], X[:, 1], c=labels_km, cmap='viridis', alpha=0.6, s=20)
axes[1].scatter(scaler.inverse_transform(kmeans.cluster_centers_)[:, 0],
                scaler.inverse_transform(kmeans.cluster_centers_)[:, 1],
                c='red', marker='X', s=200, edgecolors='black')
axes[1].set_title(f'K-Means (轮廓系数: {silhouette_score(X_scaled, labels_km):.3f})', fontsize=12)
axes[1].set_xlabel('年收入(千元)')

# DBSCAN
dbscan = DBSCAN(eps=0.4, min_samples=5)
labels_db = dbscan.fit_predict(X_scaled)
n_clusters_db = len(set(labels_db)) - (1 if -1 in labels_db else 0)
# 将噪声点统一算轮廓系数（近似）
if n_clusters_db >= 2:
    mask = labels_db != -1
    sil_db = silhouette_score(X_scaled[mask], labels_db[mask]) if mask.sum() > 1 else 0
else:
    sil_db = 0
axes[2].scatter(X[:, 0], X[:, 1], c=labels_db, cmap='viridis', alpha=0.6, s=20)
axes[2].set_title(f'DBSCAN (簇数={n_clusters_db})', fontsize=12)
axes[2].set_xlabel('年收入(千元)')

# 层次聚类（AGNES）
agg = AgglomerativeClustering(n_clusters=3)
labels_agg = agg.fit_predict(X_scaled)
axes[3].scatter(X[:, 0], X[:, 1], c=labels_agg, cmap='viridis', alpha=0.6, s=20)
axes[3].set_title(f'层次聚类 (轮廓系数: {silhouette_score(X_scaled, labels_agg):.3f})', fontsize=12)
axes[3].set_xlabel('年收入(千元)')

plt.tight_layout()
plt.savefig('clustering_comparison.png', dpi=150, bbox_inches='tight')
print("聚类对比图已保存为 clustering_comparison.png")

# 解释客户分群
y_km = labels_km
print("\nk-means 各簇统计:")
for i in range(3):
    cluster_data = X[y_km == i]
    print(f"  簇{i} (n={len(cluster_data)}): "
          f"平均收入={cluster_data[:,0].mean():.1f}k, "
          f"平均消费={cluster_data[:,1].mean():.1f}k")
```

### 输出
```
聚类对比图已保存为 clustering_comparison.png

k-means 各簇统计:
  簇0 (n=98): 平均收入=59.3k, 平均消费=53.4k
  簇1 (n=98): 平均收入=117.6k, 平均消费=96.9k
  簇2 (n=104): 平均收入=30.1k, 平均消费=15.7k
```

### 解读
- k-means清晰地把客户分成了三类：低收入低消费（节俭型）、中等收入中等消费（均衡型）、高收入高消费（土豪型）
- 轮廓系数衡量聚类质量——越接近1越好
- 对这三类客户，超市可以制定不同的策略：给节俭型发优惠券、给均衡型推新品、给土豪型推高端会员卡
- DBSCAN调节eps参数可能产生不同数量的簇——需要业务经验来调

---

## 小结

> 聚类没有"正确答案"——分组的好坏取决于你的业务目标。k-means简单高效但要指定k，DBSCAN可以发现任意形状的簇还能自动识别噪声，层次聚类给你一棵可以任意剪裁的树。选择哪个，取决于你的数据长什么样和你想要什么。
